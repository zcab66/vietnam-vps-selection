## IP类型：机房IP、原生IP、住宅IP、双ISP，到底差在哪

这四个词经常被混用，但含义完全不同。

**机房IP（数据中心IP）**：IP注册在数据中心或云服务商名下。各大IP数据库会把它标记为hosting或data center。TikTok这类平台扫到这种标记，会认为这不是真实用户，流量分发直接受影响。

**原生IP**：IP的注册地和机房所在地一致，不是从别的国家广播过来的。原生IP解决的是“地区匹配”问题，比如你想运营越南区账号，IP得真的是越南的。但它不解决“像不像真实用户”的问题。

**住宅IP**：IP来自家庭宽带运营商，在数据库里被标记为ISP或住宅用户。这类IP的行为特征和普通家庭用户一致，平台风控很难区分。

**双ISP**：在ping0、scamalytics、IPinfo这类数据库里，同时被识别为住宅用户IP和ISP类型IP。可以理解为住宅属性的加强版认证。

丽萨主机越南节点用的是西贡邮电（SPT）的小众宽带IP段，第三方测评显示ping0识别为住宅家宽属性，scamalytics欺诈值为0，IPinfo的Company字段显示ISP类型。每台机器默认1个IPv4，另外免费送5个原生越南IPv6。

这个IP属性对做TikTok的意义，在第三方测评里有直接体现：移动网络下TikTok直播“表现亮眼”。但这个结论有边界——**住宅IP不等于永久不被风控**，IP段纯净度、账号操作方式、内容本身都会影响结果，没有任何服务商能保证100%不被封。

## 常见问题

**越南VPS选河内还是胡志明市？**
看你的用户和业务在哪。做越南北部本地业务、希望陆路方向延迟低一些，选河内（莱卡云、HostingViet）。做越南全国市场或辐射东南亚，选胡志明市（丽萨主机、UCloud）。胡志明市到新加坡、马来西亚的互联通常更好。

**原生IP和住宅IP有什么区别？**
原生IP指IP注册地和机房所在地一致，解决“地区对不对”的问题。住宅IP指IP来自家庭宽带运营商，在数据库里标记为住宅用户，解决“像不像真实用户”的问题。双ISP是住宅属性的加强版，同时被识别为住宅IP和ISP类型IP。做TikTok要看的是后两者。

**做TikTok一定要住宅IP吗？**
